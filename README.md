# پروژه آمار — مسیر الف: NHANES 2021–2023

**موضوع:** مقایسه درون‌فردی قرائت اول و سوم فشارخون سیستولیک در بزرگسالان آمریکا  
**نسخه تحویل:** `phase-2` — احتمال و توزیع‌های احتمالی

## وضعیت فازها
| فاز | وضعیت | خروجی |
|---|---|---|
| ۱ — شناخت داده و آمار توصیفی | تکمیل‌شده | `reports/phase1.pdf` و `reports/phase1/` |
| ۲ — احتمال و توزیع‌های احتمالی | تکمیل‌شده | `reports/phase2/phase2.pdf` و جدول‌ها |

## بازتولید کامل تحلیل‌ها
1. Python 3.10 یا جدیدتر نصب کنید.
2. سه فایل خام `DEMO_L.xpt`، `BPXO_L.xpt` و `BMX_L.xpt` را مطابق `data/README.md` داخل پوشه `data/` قرار دهید. فایل‌های خام عمداً داخل ZIP نیستند.
3. وابستگی‌ها را نصب کنید:
   ```bash
   pip install -r requirements.txt
   ```
4. از ریشه پروژه اجرا کنید:
   ```bash
   python src/phase1.py
   python src/phase2.py
   python src/make_phase2_report.py
   ```
5. گزارش فاز دوم در `reports/phase2/phase2.pdf` و نسخه HTML در `reports/phase2/phase2.html` ساخته می‌شود. جدول‌های CSV در `reports/phase2/tables/` و شکل‌ها در `figures/phase2/` ذخیره می‌شوند.

برای بازسازی PDF فاز اول، پس از اجرای `phase1.py`، اسکریپت `src/make_report.py` را نیز اجرا کنید؛ این اسکریپت به Chromium/Google Chrome نیاز دارد.

## ساختار بسته
- `PROJECT_CARD.md` — کارت پروژه و مشخصات تحلیل
- `data/README.md` — منبع، لینک‌ها و دستور دریافت داده
- `src/phase1.py` و `src/make_report.py` — کد فاز اول
- `src/phase2.py` و `src/make_phase2_report.py` — کد تحلیل و گزارش فاز دوم
- `reports/phase1/` و `reports/phase2/` — گزارش‌ها، آمار و جدول‌ها
- `figures/phase1/` و `figures/phase2/` — شکل‌های خروجی
- `requirements.txt` — وابستگی‌ها

## ملاحظات داده و تفسیر
- واحد مشاهده یک شرکت‌کننده یکتا با شناسه `SEQN` است؛ نمونه تحلیلی شامل ۵٬۸۴۲ نفر با سن حداقل ۲۰ سال، معاینه‌شده در MEC و دارای هر سه قرائت سیستولیک معتبر است.
- فایل‌های خام NHANES به دلیل حجم و مطابق دستورالعمل پروژه در ZIP قرار نگرفته‌اند.
- احتمال‌های خام و محاسبات کوواریانس در این فاز توصیفی‌اند. وزن‌دار کردن احتمال H1 در زیرنمونه کامل‌موارد به‌تنهایی برآورد رسمی شیوع ملی نیست.
- برای استنباط جمعیتی باید وزن، طبقه‌ها (`SDMVSTRA`)، خوشه‌ها (`SDMVPSU`) و تحلیل زیرجمعیت با روش‌های مناسب طرح نمونه‌گیری پیچیده لحاظ شوند.

## یکسان‌سازی قالب گزارش با فاز اول
- فونت متن فارسی گزارش فاز دوم مانند فاز اول `DejaVu Sans` است.
- رنگ تیترها، خطوط جداکننده، جدول‌ها، کادرهای توضیحی، اندازه متن و حاشیه صفحه با قالب گزارش فاز اول هماهنگ شده‌اند.
- کدهای تحلیلی با فاصله‌گذاری و تورفتگی استاندارد پایتون مرتب شده‌اند؛ نام متغیرها و شناسه‌های اصلی NHANES برای بازتولیدپذیری حفظ شده‌اند.


در برخی سیستم‌های لینوکس و macOS، نصب WeasyPrint ممکن است به کتابخانه‌های سیستمی از جمله Pango نیاز داشته باشد؛ در صورت خطای نصب یا ساخت PDF، راهنمای نصب رسمی WeasyPrint متناسب با سیستم‌عامل بررسی شود.
