# Phase 2 deliverables

- `phase2.pdf`: گزارش نهایی فارسی
- `phase2.html`: نسخه HTML گزارش
- `stats.json`: خلاصه پارامترهای کلیدی و کنترل‌های بازتولید
- `tables/`: جدول‌های رویدادها، احتمال‌های شرطی، استقلال، بیز، مدل‌های توزیعی، نرمالیت، ممان‌ها و وزن‌دهی

برای بازسازی، ابتدا داده‌های خام را طبق `../../data/README.md` دریافت کنید و سپس `python src/phase2.py` و `python src/make_phase2_report.py` را از ریشه پروژه اجرا کنید.
